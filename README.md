#  House Price Prediction using Machine Learning

##  Problem Statement
The objective of this project is to build a machine learning model that predicts house prices based on different housing features.

##  Dataset
Dataset used: Boston Housing Dataset

Dataset Link:
https://raw.githubusercontent.com/selva86/datasets/master/BostonHousing.csv


## Objectives
- Perform data preprocessing
- Prepare features and target variables
- Split dataset into training and testing sets
- Train machine learning model
- Predict house prices
- Evaluate model performance

## Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook / Google Colab


## Data Preprocessing Steps
- Imported dataset using Pandas
- Cleaned column names
- Checked dataset structure
- Separated features and target variable
- Applied train-test split for model training


##  Machine Learning Model
Model Used:
- Random Forest Regressor

##  Model Evaluation
The model performance was evaluated using RMSE (Root Mean Square Error).


##  Result
The machine learning model successfully predicted house prices with good accuracy and demonstrated the complete ML workflow from preprocessing to evaluation.
